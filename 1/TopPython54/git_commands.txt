Команды Git, которые я использовал для создания проекта:

1. git init
Эта команда создает новый пустой Git-репозиторий в текущей папке. Внутри появляется скрытая папка .git, где хранится вся история изменений.

2. git config --global user.name "Дмитрий Поддубный"
Настраивает имя пользователя, которое будет прикрепляться к моим коммитам. Флаг --global значит, что это применится ко всем проектам на компьютере.

3. git config --global user.email "okolesh11@mail.ru"
Настраивает email для коммитов. Тоже глобально, чтобы GitHub знал, кто автор изменений.

4. git add .
Добавляет все новые и измененные файлы в индекс (область подготовки). Теперь Git знает, какие файлы нужно включить в следующий коммит.

5. git commit -m "Первый коммит: создан файл с описанием команд Git"
Сохраняет изменения из индекса в историю репозитория. С помощью -m я сразу пишу короткое описание того, что было сделано.

6. git remote add origin https://github.com/ВАШ_ЛОГИН/TopPython54.git
Привязывает локальный репозиторий к удаленному на GitHub. "origin" - это стандартное имя для основного удаленного сервера.

7. git push -u origin main
Отправляет мои локальные коммиты на GitHub в ветку main. Флаг -u запоминает связь, чтобы в будущем можно было писать просто git push.
