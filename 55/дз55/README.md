# Домашнее задание №55 - сайт с базой данных

Это продолжение сайта про личные финансы. Меню и текст страниц перенесены в базу данных site.db.

## В проекте

- Flask приложение;
- SQLite база;
- шаблоны HTML;
- стили CSS.

## Запуск

`powershell
python -m pip install -r requirements.txt
python app.py
`

Сайт откроеться на http://127.0.0.1:5000
