# Домашнее задание №56

Генератор паролей на Django. Пользователь выбирает длину пароля и отмечает, что нужно добавить:

- большие буквы;
- цифры;
- спец символы.

## Запуск

```powershell
python -m pip install -r requirements.txt
python manage.py runserver
```

После запуска сайт будет доступен по адресу http://127.0.0.1:8000
