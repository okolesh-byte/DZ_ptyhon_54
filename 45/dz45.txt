Задание 45

1. Вывести данные о товаре в алфавитном порядке.
SELECT *
FROM SallerGoods
ORDER BY Goods;

2. Вывести посредников, поставляющих товар для фирмы.
SELECT *
FROM Seller
WHERE Status LIKE '%посред%';

3. На какую сумму было всего куплено каждого товара фирмой.
SELECT Goods, SUM(CostUnit * Count) AS Summa
FROM SallerGoods
GROUP BY Goods;

4. Определить какой товар был куплен у посредников.
SELECT DISTINCT SallerGoods.Goods
FROM SallerGoods, Seller
WHERE SallerGoods.INNSeller = Seller.INNSeller
AND Seller.Status LIKE '%посред%';

5. Выводит название товара и прибыль, полученную от его продажи.
SELECT SallerGoods.Goods, SUM((ClientGoods.CostUnit - SallerGoods.CostUnit) * ClientGoods.Count) AS Profit
FROM SallerGoods, ClientGoods
WHERE SallerGoods.ID = ClientGoods.ID
GROUP BY SallerGoods.Goods;

6. Определите какие клиенты не покупали подсолнечное масло.
SELECT *
FROM Client
WHERE INNClient NOT IN (
    SELECT ClientGoods.INNClient
    FROM ClientGoods, SallerGoods
    WHERE ClientGoods.ID = SallerGoods.ID
    AND SallerGoods.Goods LIKE '%подсолнечное масло%'
);

7. Показать код и наименование товара, купленного посредниками.
SELECT SallerGoods.Code, SallerGoods.Goods
FROM SallerGoods, Seller
WHERE SallerGoods.INNSeller = Seller.INNSeller
AND Seller.Status LIKE '%посред%';

8. Вывести список клиентов и сумму прибыли за каждый товар, полученную от продажи черного перца.
SELECT Client.Client, SallerGoods.Goods, SUM((ClientGoods.CostUnit - SallerGoods.CostUnit) * ClientGoods.Count) AS Profit
FROM Client, ClientGoods, SallerGoods
WHERE Client.INNClient = ClientGoods.INNClient
AND ClientGoods.ID = SallerGoods.ID
AND SallerGoods.Goods LIKE '%перец черный%'
GROUP BY Client.Client, SallerGoods.Goods;

9. Выведите список товаров в обратном порядке, если товар куплен у производителя и продан в кафе.
SELECT DISTINCT SallerGoods.Goods
FROM SallerGoods, Seller, ClientGoods, Client
WHERE SallerGoods.INNSeller = Seller.INNSeller
AND SallerGoods.ID = ClientGoods.ID
AND ClientGoods.INNClient = Client.INNClient
AND Seller.Status LIKE '%производ%'
AND Client.Status LIKE '%кафе%'
ORDER BY SallerGoods.Goods DESC;
