# Домашнее задание №52 - сайт на Flask

Небольшой учебный сайт про личные финансы. Тут есть 4 страницы и одна страница ошибки 404.

## Что тут есть

- главная страница;
- страница про доходы;
- страница про расходы;
- страница контактов.

Все страницы наследуються от ase.html. Стили лежат в static/css/style.css.

## Запуск

`powershell
python -m pip install -r requirements.txt
python app.py
`

После запуска сайт откроеться по адресу http://127.0.0.1:5000
